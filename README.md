# 我想永远陪着你 · 语音（Astrbot_Amo_Speechsound）

给「我想永远陪伴你」配一副声音。

前面三块各管一件事：陪伴负责活成一个人，数据负责记住，生图负责被看见。
这一块只负责**被听见**——而且刻意不做成「把回复念一遍」的 TTS：

> 念什么、什么时候念、用什么语气念，由她自己决定。

## 它和普通 TTS 插件的区别

普通 TTS 插件是「把文字转成音频」。问题是文本天生不是给人听的：里面有链接、
代码、清单、括号里的舞台说明，念出来是灾难；而且模型一旦能自由调用，就会在
群里刷语音。

这里的做法：

| 维度 | 常见做法 | 本插件 |
| --- | --- | --- |
| 谁决定开口 | 模型自由调 / 全局开关 | Amo 用工具主动开口；插件只拦硬伤 |
| 念什么 | 整段回复 | 先清洗（去代码、链接、@、表情），再判断长度 |
| 什么语气 | 一个固定音色 | 按场景切音色 + `mood` 表演指令 |
| 出错了 | 报错给用户 | 静默降级（Edge 兜底 / 退回文字） |
| 音色 | 手抄 voice_id | 面板点「拉取」，按场景分配 |

## 安装

把整个目录放进 `AstrBot/data/plugins/`，重载插件即可。也可以在 AstrBot 的
插件页用仓库地址安装：

```text
https://github.com/GM888888456/Astrbot_Amo_Speechsound
```

依赖只有 `aiohttp`（AstrBot 自带），不需要额外装包。

## 配置

打开插件详情页，四个标签页：

- **概览**：当前后端、密钥状态、今天说了几句、上次开口时间、陪伴插件是否连上；
- **配置**：后端、`api_base`、`api_key`、音色、语速、限额、开关；
- **音色**：点「拉取音色」从账号拉回可用音色，再按场景分配；
- **记录**：最近每一次「发/不发」以及原因。

### 关于 API Key

主后端是 [Breeze Blue](https://breezeblue.ai)（Breeze TTS 2），它的表演感是
这个插件的前提——没有 `instructions` 语气指令，声音就只是朗读。

Key 需要**你自己注册**，在 `breezeblue.ai` 的 API 密钥页创建，形如 `brz_...`。
免费账户每天有 400 积分（约 2000 个汉字，够一百来条短语音），日常用不完。

> 为什么插件不内置一个共享的 key：那违反对方服务条款（禁止转售、禁止绕过
> 限额），账号会被封，所有用这个插件的人一起哑掉。音色也不是文件，是服务端
> 资产，没有「打包内置」这回事。插件内置的是**音色目录**，不是音色。

### 场景与音色

拉取音色后，在「音色」页选一个场景（日常 / 睡前 / 撒娇 / 难过 / 生气 / 开心 /
在家 / 出门），再点某个音色的「设为这个场景」。没配的场景用默认音色。

场景是自动判断的：先说「晚安、早点睡」走睡前，说「想你、抱抱」走撒娇，读不到
情绪时再看日程——在家用在家音色，在外面用出门音色。

### 开口的规则

**Amo 主动调用时**（工具 `amo_speak`）只拦硬伤：

- 清洗后没字了；
- 太长（超过每段上限 × 最多段数）；
- 群聊且没开「允许群聊发语音」；
- 今天的条数用完了。

其余一律放行——她已经决定要说了，插件不该再用阈值把她按住。

**兜底路径**（默认关闭）才用打分：私聊 +0.2、深夜 +0.18、短句 +0.18、情绪词
按权重加分，疑问句 -0.12，低于阈值（默认 0.6）就不发。这一层全在本地算，
不额外调模型，不产生任何 tokens。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/speak <文本>`（别名 `/语音`） | 手动合成一条，用来试音色；不受阈值限制 |
| `amo_speak`（LLM 工具） | Amo 主动开口，参数 `text`、`mood`、`scene` |

## 后端

| 后端 | 说明 |
| --- | --- |
| `breeze` | Breeze Blue，主后端，支持语气指令与音色目录 |
| `openai` | 任何 OpenAI 兼容的 `POST /audio/speech` |
| `edge` | 微软 Edge 朗读，免费，作为最后兜底（需要 `pip install edge-tts`） |

兜底逻辑：主后端返回 5xx / 429 / 超时（可重试的错误）时，先看 AstrBot 里有没有
配置好的 TTS provider——有就用它，不额外装包；没有再退到 Edge 朗读。4xx 这类配置
错误不兜底，因为换了也念不出来，还会掩盖真正的问题。

> Edge 的协议里带微软的 DRM 签名，那套算法来自 GPL 的 `edge-tts` 项目。为了不把
> 本插件的 MIT 协议污染掉，这里**不内嵌实现**，只在运行时可选地调用 `edge_tts`
> 包：装了就用，没装就给一句能照做的提示。

## 数据

都放在 `data/plugin_data/Astrbot_Amo_Speechsound/`，不落在插件安装目录：

- `state.json`：今日计数、上次开口时间、场景音色分配、最近 60 条记录；
- `voices.json`：拉取到的音色目录缓存；
- `audio/`：最近几条音频（默认只留 8 条，`keep_audio` 打开则全留）。

## 版本号规则

`x.y.z`，第二位和第三位都是 0–9，**逢十进一**：3.8.9 → 3.9.0，3.9.9 → 4.0.0，
9.9.9 → 10.0.0（不是 1.0.0.0）。首位不做限制。

- 测试版：动第三位；
- 发布版：动第二位、第三位归零；
- 大版本：首位 +1。

`python tools/check_version.py` 会校验 `metadata.yaml` / `CHANGELOG.md` /
`README.md` / `main.py` 四处一致，并检查仓库地址写法。
